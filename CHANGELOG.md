# Changelog

All notable changes to this mod. Versions follow [Semantic Versioning](https://semver.org); each one is a git tag (`v1.1.0`) and a GitHub release.

## [1.1.0] - 2026-11-04

### Added

- Tab rows show the agent's session name in grey after the tab's name (`Oh My Pi  TAB: Auto-name tabs`), taken from the title the agent gives its terminal.
- "Hide session names" / "Show session names" in a space's right-click menu, and the `herdr-spaces-navigation.sessions` command, hide or show them on every tab row.

## [1.0.0] - 2026-11-03

First release of the fork of [herdr-space-folders](https://github.com/jankeesvw/herdr-space-folders).

### Added

- One row per tab under each space: program icon, name, agent status. Click to show it, double-click to rename, right-click for Herdr's tab menu; the space's chevron folds them.
- `alt-up` / `alt-down` step tab to tab, then to the next space or folder, in the order the list shows.
- 14 colors in a space's right-click menu; 15 folder colors.
